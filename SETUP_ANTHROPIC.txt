========================================
CONFIGURACIÓN DE ANTHROPIC PARA HUMANO
========================================

Para que los logs de Toon se guarden correctamente, agrega estas líneas a tu archivo .env:

# Anthropic Claude API (mismo que CLAUDE_API_KEY)
ANTHROPIC_API_KEY=tu_api_key_aquí
ANTHROPIC_MODEL=claude-3-5-sonnet-20241022
ANTHROPIC_API_URL=https://api.anthropic.com/v1
ANTHROPIC_MAX_TOKENS=4096
ANTHROPIC_TEMPERATURE=0.7
ANTHROPIC_TIMEOUT=30

========================================
PASOS RÁPIDOS:
========================================

1. Abre tu archivo .env en el proyecto humano
2. Si ya tienes CLAUDE_API_KEY configurado, copia ese valor
3. Agrega: ANTHROPIC_API_KEY=el_mismo_valor_de_CLAUDE_API_KEY
4. Guarda el archivo
5. Ejecuta: php artisan config:clear
6. Ejecuta: php artisan optimize:clear

========================================
VERIFICAR QUE FUNCIONA:
========================================

Después de configurar, ejecuta:

php artisan tinker

Y luego:

config('anthropic.api_key')

Deberías ver tu API key. Si ves "null", revisa que hayas guardado correctamente el .env.

========================================
GENERAR PERFIL ASTROLÓGICO DE PRUEBA:
========================================

Una vez configurado, ve a un contacto con fecha de nacimiento y genera su perfil astrológico.
Luego verifica los logs:

php artisan tinker

\App\Models\TokenUsageLog::latest()->first()

Deberías ver el registro de la llamada con los tokens ahorrados.
