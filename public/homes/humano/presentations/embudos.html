EMBUDOS · DOS PIEZAS

No es lo mismo un embudo que una automatización

El embudo conversa. La automatización ejecuta. Juntos cierran el ciclo sin perder el hilo.

Embudo

Flujo conversacional

Grafo de pasos con salidas tipadas. El usuario responde y el embudo decide el siguiente camino sin que intervengas.

  • Editor visualArrastrá pasos, conectá salidas y marcá el de entrada.
  • Respuestas tipadasSí/No, opción, email, fecha, texto libre o fallback.
  • Varios canalesCorre en chat del panel, WhatsApp o API pública.
  • Ramifica el diálogoCada salida puede ir a otro paso o cerrar el flujo.

EMBUDOS · RESPUESTAS

Cada salida espera un tipo de respuesta

Así el embudo entiende qué dijo el usuario y elige el camino correcto.

Sí / Noyes_no

Confirmaciones rápidas: aceptar, cancelar o continuar sin ambigüedad.

síno, gracias→ Confirmar / Cancelar
Opciónchoice

Coincide por palabra clave cuando el usuario elige un camino concreto.

citacontactosoporte→ Rama
Texto librefree_text

Captura el mensaje completo cuando necesitás el contenido, no solo una opción.

Necesito factura del mes pasado→ Guardar texto
Email / Teléfonoemail · phone

Valida el dato de contacto antes de seguir o disparar una automatización.

ana@acme.com+34 600…→ Alta contacto
Fechadate

Ideal para agendar, pedir plazos o confirmar un día y hora.

mañana 10:00viernes→ Crear cita
Cualquier otrafallback

Red de seguridad: si no coincide ninguna salida tipada, el embudo no se queda trabado.

mmm no sé→ Repreguntar / Cierre
