CMS · FLUJO

De Humano a WordPress y viceversa

Cuatro pasos: instalas los plugins IDONEO, conectas la sincronización, editas el contenido y ambos sitios quedan alineados.

01

Instala plugins

Descarga los ZIP oficiales IDONEO desde la ayuda de Humano e instálalos en tu WordPress de producción.

  • Ve a /help/plugins y descarga los tres ZIP
  • En wp-admin: Plugins → Añadir nuevo → Subir plugin
  • Orden recomendado: Custom Fields, CMS Sync y Chat
  • Activa cada plugin tras instalarlo
Custom Fields + Sync + Chat
02

Conecta el equipo

Configura URL de Humano, Team ID, webhook secret y token de API en los ajustes de cada plugin.

  • CMS Sync: URL, Team ID y webhook secret
  • El secret debe coincidir con Ajustes del equipo en Humano
  • Chat: URL de Humano y token de API del equipo
  • En producción usa tu dominio real (no .test) y SSL activo
Misma credencial del equipo
03

Edita contenido

Crea o actualiza entradas y páginas en Humano o en WordPress: categorías, etiquetas y campos personalizados viajan con el post.

  • Entradas y páginas en /cms/posts y /cms/pages
  • Slug automático desde el título; permalink editable
  • Categorías jerárquicas y etiquetas separadas por comas
  • Editor Quill con imágenes desde la biblioteca de medios
Editor tipo WordPress
04

Sincroniza

CMS Sync notifica cambios en tiempo real; Humano empuja o importa posts, taxonomías y valores de IDONEO Custom Fields.

  • Webhook al guardar o borrar en WordPress
  • Humano empuja cambios locales al remoto en segundo plano
  • Categorías y etiquetas nuevas se crean en ambos lados
  • Campos ICF viajan como icf_fields en la REST API
Bidireccional

Plugins IDONEO para WordPress

Tres extensiones oficiales: campos personalizados, sincronización de contenido y chat conectado al asistente de Humano.

IDONEO Custom Fields

Campos personalizados nivel PRO para cualquier tipo de contenido, sin depender de ACF.

  • Texto, WYSIWYG, imagen, galería, repeater y flexible content
  • Grupos de campos con reglas de ubicación por post type
  • Páginas de opciones para ajustes globales del sitio
  • Valores expuestos en REST como icf_fields
  • Humano los importa y empuja junto con cada entrada
Sin configuración extra

IDONEO CMS Sync

Puente en tiempo real entre el CMS de Humano y tu WordPress.

  • Webhook al guardar, actualizar o eliminar posts y páginas
  • Sincroniza medios adjuntos y metadatos del contenido
  • Importa y empuja categorías y etiquetas automáticamente
  • Pull completo desde Ajustes del equipo o por webhook
  • Configuración en Ajustes → IDONEO CMS Sync para Humano
Tiempo real

IDONEO Chat for Humano

Widget de chat en tu sitio WordPress conectado al asistente del equipo.

  • Shortcode para insertar el chat en cualquier página
  • Respuestas del asistente con contexto de tu equipo
  • Puede consultar entradas y páginas publicadas del CMS
  • Token de API en Ajustes → IDONEO Chat for Humano
  • Verificación SSL recomendada en producción
Shortcode + ajustes
