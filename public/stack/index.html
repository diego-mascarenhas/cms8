4 Base de datos

PostgreSQL Base de datos principal en producción y desarrollo.

El modelo de datos y las consultas están pensados para PostgreSQL. La capa de acceso usa Eloquent, que abstrae el driver y permite mantener compatibilidad con MySQL en entornos legacy, migraciones históricas o conexiones secundarias sin reescribir la lógica de negocio.

ComponenteUso
PostgreSQLBD principal (pgsql)
MySQLCompatibilidad Eloquent, conexión legacy (mysql_legacy)
SQLiteTests automatizados (in-memory)

SesionesDriver database
